# Обзор проекта

Лабы по дисциплине "Современные методы анализа сетевого трафика"

Ключевые компоненты:
- папка `src/classification` — pipeline для классификации (подготовка данных, обучение, оценка)
- папка `src/regression` — пример регрессии и предсказания зарплат
- папка `src/parsing` — примеры парсинга и подготовки данных

См. другие главы в папке `docs/` для установки, запуска и описания структуры проекта.
