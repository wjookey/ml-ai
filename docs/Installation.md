# Установка

Требования:
- Python 3.8 или новее
- Рекомендуемые библиотеки: `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`

Установка в виртуальном окружении (пример):

1. Создать и активировать venv:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Установить зависимости:

```powershell
pip install numpy pandas scikit-learn matplotlib seaborn
```
