# Данные

В проекте используются небольшие датасеты в виде бинарных файлов NumPy и CSV-файлов, размещённых рядом с соответствующими скриптами:

- `src/classification/X_data.npy`, `src/classification/y_data.npy` — данные для задачи классификации
- `src/classification/feature_names.npy` — названия признаков
- `src/regression/X_data.npy`, `src/regression/y_data.npy` — данные для регрессии
- `src/parsing/X_data.npy`, `src/parsing/y_data.npy` — данные, полученные в результате парсинга датасета
- `src/regression/predicted_salaries.csv` — пример выходных данных регрессии
