# Обучение моделей

Классификация:
- Скрипт `src/classification/train_and_evaluate_model.py` выполняет обучение модели, кросс-валидацию и сохраняет отчёты об оценке.
- `calculate_baseline.py` может использоваться для расчёта базовой точности для сравнения.

Регрессия:
- `src/regression/model_trainer.py` отвечает за обучение модели регрессии и сохранение предсказаний в `predicted_salaries.csv`.
- `src/regression/salary_predictor.py` содержит логику предсказания на новых данных.

Рекомендации:
- Используйте виртуальное окружение и фиксируйте зависимости.
- Добавляйте логирование и сохранение контрольных точек моделей по мере усложнения экспериментов.
