# Классификация и оценка моделей машинного обучения

Проект находится в каталоге `src/classification` и предназначен для обучения
и оценки моделей классификации на подготовленных данных, а также для анализа
качества предсказаний и распределения классов.

## Структура проекта

- `src/classification/app.py` – точка входа приложения. Запускает полный конвейер
  классификации: загружает данные, анализирует распределение классов, обучает модель,
  генерирует отчеты и визуализирует результаты.

- `src/classification/load_data.py` – загрузка данных из файлов `.npy`.
  Функция `load_data()` читает матрицу признаков `X` и целевую переменную `y`,
  подготовленные на этапе парсинга.

- `src/classification/prepare_data.py` – разделение данных и масштабирование.
  Выполняет разделение данных на обучающую и тестовую выборки,
  затем применяет стандартизацию признаков с помощью `StandardScaler`.

- `src/classification/train_and_evaluate_model.py` – обучение модели и его оценка
  с кросс-валидацией. По умолчанию использует `LogisticRegression`, но поддерживает
  любые модели scikit-learn. Вычисляет точность и средние баллы кросс-валидации.

- `src/classification/generate_classification_report.py` – создание детального отчета
  классификации с метриками precision, recall, f1-score для каждого класса,
  а также поддержкой для макро- и взвешенных усредненных значений.

- `src/classification/plot_confusion_matrix.py` – визуализация матрицы ошибок
  (confusion matrix) с помощью тепловой карты. Помогает понять, какие классы
  часто путаются моделью.

- `src/classification/analyze_class_distribution.py` – анализ уникальных классов
  и их частоты в целевой переменной. Возвращает список уникальных классов
  и количество примеров для каждого.

- `src/classification/plot_class_distribution.py` – визуализация распределения классов
  в виде столбчатой диаграммы. Показывает баланс/дисбаланс классов в данных.

- `src/classification/calculate_baseline.py` – расчет базовой точности (baseline).
  Вычисляет точность "наивного" классификатора, который всегда выбирает
  самый часто встречаемый класс.

- `src/classification/analyze_class_errors.py` – анализ ошибок классификации.
  Определяет, какие классы чаще всего ошибочно классифицируются и в какие классы
  происходит ошибочное предсказание.

- `src/classification/X_data.npy` и `y_data.npy` – примеры подготовленных данных
  (признаки и целевая переменная), загружаемые при запуске `app.py`.

- `src/classification/feature_names.npy` – массив NumPy с названиями признаков,
  используется для интерпретации результатов модели.

## Установка и запуск

Проект требует следующих зависимостей:

```bash
pip install numpy pandas scikit-learn matplotlib seaborn
```

Запустить процесс классификации можно так:

```bash
python src/classification/app.py
```

Скрипт выполняет следующие операции:
1. Визуализирует распределение классов в исходных данных
2. Загружает данные из `.npy` файлов
3. Анализирует распределение классов
4. Подготавливает данные (разделение и масштабирование)
5. Обучает модель логистической регрессии с кросс-валидацией
6. Генерирует отчет классификации
7. Визуализирует матрицу ошибок
8. Анализирует ошибки классификации
9. Вычисляет и сравнивает с базовой точностью

## Результаты и метрики

При запуске скрипт выводит:
- Статистику классов в данных
- Точность модели на тестовых данных
- Результаты кросс-валидации
- Детальный отчет классификации (precision, recall, f1-score)
- Матрица ошибок
- Анализ самых частых ошибок
- Сравнение точности модели с базовой точностью
