# Линейная регрессия

В каталоге `src/regression` находится проект для обучения, оценки модели линейной регрессии на подготовленных данных и предсказания зарплат.

## Структура проекта `src`

- `src/regression/app.py` – точка входа приложения. Запускает выполнение задачи регрессии.

- `src/regression/model_trainer.py` – класс для обучения регрессионной модели (Ridge) на
  данных из `X_data.npy` и `y_data.npy`; включает загрузку, разбиение,
  тюнинг гиперпараметров и вычисление метрик.

- `src/regression/salary_predictor.py` – оболочка для загрузки обученной модели и
  выполнения предсказаний на новых данных.

## Установка и запуск

Все подсистемы используют единый набор зависимостей:

```bash
pip install numpy pandas scikit-learn
```

Запустить процесс регрессии можно так:

```bash
pip src/regression/app.py path/to/X_data.npy
```

## Результаты

Проект демонстрирует полный цикл ML‑разработки: от извлечения и
предобработки данных до обучения и оценки моделей для классификации и
регрессии. Все модули легко расширяются и снабжены логированием
для отладки.
