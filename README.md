# Примеры парсинга и подготовки данных

Проект находится в каталоге `src/parsing` и предназначен для чтения
данных из датасета HH.ru и подготовки их для машинного
обучения.

## Структура проекта

- `src/parsing/app.py` – точка входа приложения. Принимает путь к CSV‑файлу, читает
  и очищает данные, запускает пайплайн обработки и сохраняет результаты в
  `X_data.npy` и `y_data.npy`.

- `src/parsing/parsing_data.py` – основная логика обработки. Здесь реализован
  шаблон «цепочка ответственности» (`DataHandler`), набор конкретных обработчиков
  для извлечения признаков и классов:
  - извлечение пола (`SexExtractor`)
  - возраста (`AgeExtractor`)
  - зарплаты и ее конвертация в рубли (`SalaryExtractor`)
  - желаемой/последней должности, города, занятости, графика, опыта,
    образования и др.
  - фильтрация выбросов, заполнение пропусков и финальная подготовка
    признаков (one‑hot, стандартизация) при помощи либо собственного
    `DataPreparer`, либо `SklearnPreprocessor`.

  После применения цепочки метод `DataProcessingPipeline.process()` возвращает
  матрицу признаков `X` и вектор целевой переменной `y`, которые могут быть
  загружены в любой ML‑фреймворк.

  Дополнительно присутствует логирование во `data_processing.log` и в консоль.

- `src/parsing/X_data.npy` и `y_data.npy` – примеры сгенерированных массивов
  NumPy, которые создаются запуском `app.py`.

## Установка и запуск

Проект требует следующих зависимостей:

```bash
pandas numpy scikit-learn
```

Запустить обработку можно так:

```bash
python src/parsing/app.py path/to/hh.csv
```

Результат — два файла `.npy` с подготовленными признаками и метками.
